# RPS Arena

A Pygame rock-paper-scissors population simulation with an optional vertical layout for OBS and a localhost event bridge for stream-overlay testing.

## Simulation

Each entity moves through the arena and seeks a type it defeats: rock targets scissors, scissors target paper, and paper targets rock. Collisions convert the losing entity, so populations expand and contract until one type dominates. Round settings control population, speed, piece size, seek radius, seek force, and restart timing.

## Stream mode

```bash
python rps_bouncer.py --stream --preset 720p
```

The 720p and 1080p presets use portrait dimensions suitable for capture in OBS. The overlay shows population counts, wins, recent events, and supporter-style test data.

The application does **not** connect to TikTok or any streaming-platform API. Its local HTTP endpoint accepts gift-shaped test events at `127.0.0.1:8765` so a separately authorized integration can be developed later.

Example local event:

```bash
python fake_gift_bridge.py --team rock --tier small --user example --gift Test
```

Hotkeys inject the same local test events:

| Keys | Tier for Rock / Paper / Scissors |
|---|---|
| `F1` / `F2` / `F3` | small |
| `F5` / `F6` / `F7` | medium |
| `F9` / `F10` / `F11` | large |

## Install

Requirements: Python 3.10+ and SDL-compatible graphics/audio through Pygame.

```bash
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
python rps_bouncer.py
```

List audio devices with `python rps_bouncer.py --list-audio-devices`. The public config uses the default output device. For an OBS routing setup, put a specific device name in your local `stream_config.json` and decide explicitly whether fallback to speakers is acceptable.

## Assets and persistence

The original rock, paper, and scissors images are included. The sound effects are generated by `generate_sfx.py`; rerun it to reproduce them. Licensing is documented in `ASSET_LICENSES.md`.

Scores and supporter names are written to `stream_scores.json`, which is ignored because it is runtime/user data. Avoid sending real usernames into screenshots or logs without consent.

## Security and limitations

The event server binds to loopback by default. Do not change it to a LAN/public interface without authentication, request validation, rate limiting, and origin/network controls. Event payloads are untrusted input. Platform integrations must follow the platform's API, automation, and monetization terms.
